# Google スプレッドシート To Do リスト with リマインドメール

GoogleスプレッドシートでTo Doリストを管理し、締切日が近づいたら自動でリマインドメールを送信するシステムです。

## 機能

- ✅ To Doリストの管理（タスク名、担当者、締切日、ステータス）
- 📧 締切日が近づいたら自動リマインドメール送信
- ⏰ 毎日自動チェック（トリガー設定）
- 🎨 見やすいスプレッドシートフォーマット

## セットアップ方法

### 1. Googleスプレッドシートの準備

1. 新しいGoogleスプレッドシートを作成
2. シート名を「ToDoリスト」に変更

### 2. Google Apps Scriptの設定

1. スプレッドシートを開いた状態で「拡張機能」→「Apps Script」をクリック
2. 既存のコード（`function myFunction() {}`）を削除
3. `Code.gs` の内容をコピー＆ペースト
4. 「プロジェクトを保存」をクリック（💾アイコン）

### 3. 初期設定の実行

1. Apps Scriptエディタで関数選択ドロップダウンから「setupSheet」を選択
2. 「実行」ボタン（▶️）をクリック
3. 初回実行時、権限の承認が必要です：
   - 「権限を確認」をクリック
   - Googleアカウントを選択
   - 「詳細」→「（プロジェクト名）に移動」をクリック
   - 「許可」をクリック
4. スプレッドシートに戻ると、ヘッダー行とサンプルデータが作成されます

### 4. リマインド設定

1. Apps Scriptエディタで「createDailyTrigger」関数を選択
2. 「実行」ボタンをクリック
3. これで毎朝8時に自動チェックが実行されます

### 5. テスト実行（任意）

手動でリマインドメールをテストしたい場合：
1. 「sendReminders」関数を選択
2. 「実行」ボタンをクリック
3. 締切が近いタスクがあればメールが送信されます

## 使い方

### To Doリストへの入力

スプレッドシートに以下の情報を入力してください：

| 列 | 説明 | 入力例 |
|---|---|---|
| A | タスク名 | プロジェクト提案書作成 |
| B | 担当者メールアドレス | tanaka@example.com |
| C | 締切日 | 2024/01/20 |
| D | ステータス | 未着手 / 進行中 / 完了 |
| E | 備考 | 任意のメモ |

### リマインドのタイミング

以下の場合にメールが送信されます：
- **3日前**: 「もうすぐ締切です」
- **1日前**: 「明日が締切です」
- **当日**: 「本日が締切です」
- **1日後**: 「締切を過ぎています」

※ ステータスが「完了」のタスクには送信されません

## カスタマイズ

### リマインド日数の変更

`Code.gs` の以下の部分を編集：

```javascript
const REMINDER_DAYS = [3, 1, 0, -1]; // 3日前、1日前、当日、1日後
```

### トリガー時刻の変更

`Code.gs` の `createDailyTrigger` 関数内：

```javascript
.atHour(8) // 8時 → 好きな時刻（0-23）に変更
```

### メール本文のカスタマイズ

`Code.gs` の `sendReminderEmail` 関数内のメッセージを編集してください。

## トラブルシューティング

### メールが送信されない

- スプレッドシートの担当者列にメールアドレスが正しく入力されているか確認
- トリガーが設定されているか確認（Apps Script → トリガー）
- 実行ログを確認（Apps Script → 実行数）

### 権限エラーが出る

- Apps Scriptの権限を再承認してください
- Googleアカウントのセキュリティ設定を確認

### トリガーを削除したい

1. Apps Scriptエディタで左側の「トリガー」（時計アイコン）をクリック
2. 削除したいトリガーの右側の「︙」→「トリガーを削除」

## 注意事項

- Googleアカウントの1日のメール送信制限（約100通/日）に注意
- スプレッドシートは関係者と共有して共同編集可能
- トリガーは各ユーザーが個別に設定する必要があります
